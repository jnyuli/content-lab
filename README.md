# Club Stylist Content Lab

Weekly interactive content-idea editions for hairstylists, published by taya.hair for Club Stylist members.

- `template/` — the edition page and the library index.
- `assets/` — shared CSS/JS.
- `data/<slug>.json` — one edition's public data; `data/editions.json` — the library list.
- `editions/<slug>/index.html` — built pages. `index.html` — the library.
- `python3 build.py` rebuilds everything.

Research data, analytics, and internal notes are not in this repo.
